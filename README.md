# Bongo Cat: исследование Steam-клиента

Анализ установленной версии от 19 октября 2026 года. Файлы игры не изменялись, игра и её сборки не запускались.

- [Архитектура, Steam и план модификации](analysis/ARCHITECTURE.md)
- [Индекс методов и токенов REA](analysis/METHODS.md)
- `analysis/decompiled/Assembly-CSharp/`: 340 восстановленных C#-файлов игровой логики.
- `analysis/decompiled/Heathen.Steamworks/`: 268 восстановленных файлов Steam-обвязки.
- `analysis/decompiled/Helper.Runtime/`: 23 восстановленных файла вспомогательной библиотеки.
- `analysis/raw/rea-evidence.json`: экспорт доказательств REA, включая метаданные, вызовы, обращения к полям и IL-якоря.
- `analysis/raw/install-manifest.json`: размеры и SHA-256 всех 202 файлов установленной версии.

Восстановленный C# и исходные доказательства оставлены локально и исключены из Git. В Git сохраняются отчёт и навигационный индекс. Восстановленный код является представлением декомпилятора, а не оригинальным Unity-проектом; сцены, привязки Inspector, материалы и текстуры в исходный проект не восстановлены.
