# Bongo Cat Mods

Первый прототип плагина для Steam build `25936063`, Unity `6000.2.8f1`, Windows x64.

## Сборка и установка

Требуются .NET SDK, .NET Framework 4.7.2 reference assemblies и Windows Mono-профиль из установленного Unity Editor 6000.5.6f1. Пути игры можно передать параметром `-GameDirectory`. Готовый пакет уже содержит необходимые библиотеки, для его установки Unity Editor не нужен.

```powershell
./scripts/Build.ps1
./scripts/Install.ps1
```

Перед установкой закройте игру. Запускайте её обычным способом через Steam. Окно мода открывается кнопкой **Mods** на верхнем краю игрового меню. Хоткей по умолчанию не назначен; выбрать клавишу или сочетание можно в **General → Open Mods shortcut**, значок корзины отключает бинд. Во время назначения Escape отменяет выбор; иначе он закрывает окно. Окно закрывается также по клику вне панели и потере фокуса. Прозрачная область игры сохраняет click-through.

Загрузчик: [официальный BepInEx 5.4.23.5](https://github.com/BepInEx/BepInEx/releases/tag/v5.4.23.5), Windows x64. Скрипт проверяет SHA-256 архива, опубликованный GitHub. Плагин проверяет SHA-256 основной сборки игры и отказывается применять патчи при смене версии. Существующий неизвестный загрузчик автоматически не заменяется.

В пакете 0.1.1 исправлена загрузка в сборке игры с обрезанными системными библиотеками. Полные Windows-библиотеки Mono лежат в `BepInEx/unstripped_corlib` и подключаются через `dll_search_path_override`. Оригинальные файлы в Managed не заменяются. Использован Windows-профиль из локального Editor 6000.5.6f1; он проверен запуском этой игры на Unity 6000.2.8f1. Общий архив corlibs 6000.2.8 с unity.bepinex.dev не используется: его платформенный профиль вызывает `System.Native` на Windows, что соответствует [известной проблеме UnityDataMiner](https://github.com/BepInEx/UnityDataMiner/issues/3).

`UnityLogListening = false` отключает несовместимый с обрезанным Unity API перехват сообщений движка в BepInEx. Лог плагина остаётся в `BepInEx/LogOutput.log`, лог Unity — в обычном `Player.log`.

## Функции прототипа

В **0.2.2** кнопка входа в Mods стала компактной: пазл и короткая подпись, фон и цвета состояний берутся из нативной темы вкладок. Открытое окно отмечается активным состоянием кнопки. Прежняя широкая плашка над меню удалена. Жёсткая привязка F9 удалена; при обновлении хоткей остаётся выключенным. В General доступно назначение клавиши с Ctrl/Alt/Shift и очистка бинда. Выбранное сочетание сохраняется в `Input.ToggleWindow` и не срабатывает при вводе текста в игровых или модовых полях. Сборка без предупреждений; 58 проверок включают миграцию без хоткея, сохранение сочетания и его отключение после перезапуска.

В **0.2.1** каталог уплотнён: вместо рядов текстовых переключателей используются иконки с подсказками. Сверху доступны каталог, пресеты, колесо, публикация внешности и возврат штатной экипировки; ниже — коты, шляпы, эмоции, поиск с крестиком и фильтр избранного. Все 12 карточек помещаются в начальную область просмотра. Основные вкладки сохранили подписи и получили иконки. Поля ввода используют нейтральную поверхность текущей темы.

Исправлен ввод текста в созданных модом TMP-полях: настройка выполняется до включения объекта, задаётся шрифт поля и режим текста без многоточия, сохраняется placeholder. Для отсутствующих символов подключён динамический системный шрифт Segoe UI, включая кириллицу; смена темы сохраняет fallback. Пока поле мода в фокусе, штатная проверка `InputFieldCache` также считает ввод активным. Пресет можно сохранить значком дискеты или Enter. Пресеты отображаются карточками с составным изображением кота и шляпы; масштаб учитывает видимые пиксели спрайтов, а не прозрачные поля. Выбранный набор выделен рамкой, удаление — значком корзины.

Версия проверена в запущенном Steam-клиенте: ввод «Котик Ёжик» через события клавиатуры, наличие глифов, видимый текст, распознавание фокуса игрой, составные карточки и размещение всей сетки. Снимки сохранены в `artifacts/ui-0.2.1/`; временный проверочный плагин удалён. Автоматика на время тестовых запусков отключалась в памяти, настройки восстановлены. Сборка проходит без предупреждений, 55 локальных проверок зелёные.

Версия **0.2.0** добавляет избранное, пресеты внешности и редактор порядка эмоций. В **Cosmetics** появились экраны **Catalog / Presets / Emote wheel**.

- Звёздочка на карточке добавляет предмет в избранное. Избранное идёт первым; кнопка **All cosmetics / Favorites only** переключает фильтр. Подсказка при наведении показывает полное название предмета.
- В **Presets** введите название и нажмите **Save**, чтобы сохранить текущего кота и шляпу вместе. Нажатие на название применяет набор, `−` удаляет его. Сохранение с тем же именем заменяет набор. Отсутствие шляпы тоже сохраняется.
- В **Emote wheel** показаны страницы по восемь слотов. Перетаскивайте эмоцию на другой слот; для переноса между страницами отпустите её на **Previous / Next**. `−` убирает эмоцию из колеса. Порядок сразу применяется к нативному колесу и сохраняется между запусками. Пустые слоты в редакторе служат целями переноса; колесо сохраняет плотный список без промежутков.
- Меню запоминает основную вкладку, экран косметики, категорию, поисковый запрос, страницу, фильтр избранного и отдельную прокрутку каждого экрана. Окно вписывается в рабочую область экрана, содержимое прокручивается внутри. Пустая выдача объясняет, как сбросить поиск или фильтр; недоступные кнопки страниц отключены.
- **General / Lobby → Activity** показывает собственные открытия автоматикой, отправленные подарки, снятые флаги готовности и последние пять изменений состояния. Итоги относятся к текущему запуску. Снятие готовности не подтверждает выдачу предмета. После окончательной ошибки появляется **Resume after error**: кнопка возвращает предыдущие режимы автоматизации, сохраняя защиту от повторной оплаты подарков. Во время незавершённого обмена повтор недоступен; окончательно отказавший собственный сундук повторно станет доступен по штатному таймеру игры.

Все новые предпочтения записываются в существующий `BepInEx/config/local.bongocat.mods.cfg`. Установка обновления его не заменяет. Сборка 0.2.0 проходит без предупреждений; 54 проверки покрывают в том числе запись настроек в настоящий конфиг, переносы между страницами, полноту списка после 5000 перестановок, границы окна и учёт подарков без дубликатов. Графика новых кнопок проверена в предпросмотре. Новые экраны и перетаскивание ещё требуют проверки в запущенной игре.

В 0.1.13 сохранённая внешность применяется после появления кота, локального каталога и кеша изображений, без ожидания Steam Inventory. До первого восстановления готовность проверяется раз в 0,1 секунды; штатная дальнейшая сверка данных лобби остаётся раз в 2 секунды. Поздние вызовы CatCosmetics.Equip/Unequip повторно применяют выбор мода, включая штатную экипировку после получения инвентаря. Лог Saved appearance restored from local assets содержит время первого восстановления. Фактическое время нового запуска ещё нужно проверить в игре.

- **General**: установка доступного остатка очков в допустимом Steam диапазоне; возврат исходного доступного остатка текущей сессии. Верхняя граница показана в меню и равна `2147483646 - BongoMinus`.
- **Chest automation**: покупка готовых собственных сундуков, выбор косметических/эмоций. Лимита расходов нет: используются штатные проверки доступного баланса и готовности сундука.
- **Lobby**: подарки выбранным участникам либо всем в текущем лобби. Очки списываются с отправителя, предмет получает адресат. Выбранные SteamID сохраняются; подарки отправляются только присутствующим участникам.
- **Cosmetics**: поиск и выбор стандартных скинов и шляп; локальное отображение либо публикация ID внешнего вида в лобби; восстановление штатной экипировки. Во вкладке **Emotes** нажатие на карточку показывает обычную эмоцию локально и отправляет её в текущее лобби.
- **UI**: игровые спрайты панелей/кнопок, шрифты и цвета текущей темы. Окно поддерживает click-through игры через штатный UI raycast и удерживает рендер активным, пока открыто.

Мод не добавляет предметы в Steam Inventory. Передача пользовательских текстур другим клиентам и программа в трее в этот прототип не входят.

В 0.1.7 эмоции используют штатные `EmoteSpawner.SpawnEmoteParticle` и `SteamMultiplayer.SendEmote`. Каталог содержит только слот `emote`; расходуемые предметы `consumable` сюда не включены. Для принимающего клиента используется обычный канал эмоций игры. Видимость зависит также от его настройки Hide Emotes. Вне лобби проигрывается локальная эмоция. Эмоции отправляются только по нажатию, при загрузке настроек не повторяются. Пользователь подтвердил отправку и видимость другим игрокам.

В 0.1.9 нажатие на карточку Emotes отправляет эмоцию, а отдельная кнопка `+` / `-` в углу добавляет или убирает её из штатного колеса. Текущие элементы отмечены `[Wheel]`. Переключателя режимов больше нет. Добавленные через мод ID сохраняются в `Emotes.WheelItems` и восстанавливаются после завершения штатной загрузки колеса. Проверка инвентаря не удаляет выбранные обычные эмоции; расходуемые предметы проверяются как прежде. Удаление через штатный интерфейс также убирает эмоцию из конфига мода. Автоматической отправки при восстановлении нет. Пользователь подтвердил работу колеса в 0.1.8.

Лимит восьми выбранных эмоций снят. Колесо показывает до восьми на странице; перелистывание — колёсиком мыши над колесом или стрелками слева и справа от крайних эмоций. Счётчик страниц находится над дугой. В 0.1.10 восстановлены штатный радиус и угол `20° × количество эмоций` на страницу, без расширения под прозрачные поля прямоугольников кнопок. Неполная последняя страница расположена симметрично. Дуга и кнопки сдвигаются внутрь рабочей области монитора с отступом 12 пикселей, учитывая панель задач; при недостатке места вся страница уменьшается. Масштаб интерфейса и перемещение кота пересчитывают раскладку. Штатные анимации остаются внутри отдельных контейнеров, чтобы не сбивать масштаб страницы. В 0.1.11 маленькие кнопки заменены единой сглаженной графикой: скруглённый фон, один тёмный контур и светлые значки с круглыми концами без двойной обводки. Графика генерируется с четырёхкратным разрешением и проверяется тем же рендерером в предпросмотре `artifacts/control-buttons-preview.png`. Прежний ControlGlyph удалён. Сборка и 38 проверок прошли; предпросмотр проверен визуально, отображение в игре ещё требует проверки. Отображение колеса подчиняется игровым настройкам. Сборка 0.1.10 и 34 проверки прошли, включая 10000 раскладок у краёв экрана, расположение стрелок сбоку и совпадение плотности со штатной формулой. Новое отображение ещё требует проверки в игре.

В 0.1.12 раздел Bongos удалён вместе с применением и восстановлением его подмены. Старый ключ в конфиге удаляется при загрузке. Превью скинов и шляп занимает карточку с отступом 4 пикселя без пустого поля под обрезанный заголовок. Выбранный предмет отмечен сглаженной скруглённой рамкой; учитывается как выбор мода, так и штатная экипировка. Выбор, восстановление экипировки и повторное открытие окна обновляют выделение. Сборка и 40 проверок прошли; новое отображение карточек ещё требует проверки в игре.

Начиная с 0.1.6 настройки записываются сразу после изменения в `BepInEx/config/local.bongocat.mods.cfg`: автопокупка, автогифт, типы сундуков, режим всех игроков, SteamID получателей, публикация внешнего вида и выбранные ID косметики. Обновление мода этот файл не заменяет. Включённая автоматизация возобновляется после запуска и появления необходимых игровых объектов; автогифт ждёт входа в лобби. Кнопка Stop all automation сохраняет выключенное состояние. При смене лобби сбрасываются только состояние очереди и отслеживаемые запросы. Сохранённая косметика применяется после загрузки каталога и изображений; неизвестные ID или несовпадение слота игнорируются. Restore equipped appearance очищает сохранённые подмены. Баланс автоматически при запуске не устанавливается.

Публикация стандартной косметики включена по умолчанию. Выбранные ID записываются в собственные данные участника лобби (`skin`, `hat`), которые штатный `CatCosmeticsMultiplayer` читает у других игроков. Внешний вид повторно применяется после входа в лобби, валидации, смены штатной экипировки и закрытия примерки. Отключение Share standard appearance in lobby возвращает в лобби штатную экипировку, сохраняя локальный выбор. Лог содержит отправленные ID и статус сверки с локальным кешем Steam. Видимость стандартных скинов у других игроков подтверждена пользователем; другу мод не требуется.

В 0.1.4 оба типа сундуков выбраны по умолчанию, переключатели доступны также во вкладке Lobby. Проверка очереди выполняется каждые 0,25 секунды; запросы подарков идут с интервалом 0,5 секунды. Открытие собственного сундука не блокирует подарки другим участникам, но его ещё не списанная стоимость учитывается при проверке доступных очков. Скрытая кнопка не блокирует автоматическое действие. Старый флаг нажатия сбрасывается только после явно наблюдавшегося перехода готовности `false → true`; уже оплаченный запрос при неизменном `true` не повторяется.

Лог подарков содержит тип, получателя и изменение состояния. Снятие готовности показывает, что сундук больше не предлагается к открытию; оно не доказывает успешную выдачу предмета. Получатель выполняет обмен у себя, иногда после анимации подарка. Автоматизация отправителя не может гарантировать скорость его анимации или ответ Steam.

До первого изменения счётчиков сохраняется JSON-копия в `BepInEx/config/local.bongocat.mods/backups/`. Она содержит исходные BongoTap/BongoMinus и SteamID, остаётся на этом компьютере. Restore balance возвращает исходный доступный остаток, если это ещё укладывается в текущую верхнюю границу. Исторические счётчики не откатываются. Lifetime-счётчик BongoBeat вручную не меняется.

В локальной схеме Steam у обоих счётчиков стоит `incrementonly = 1`. Версия 0.1.2 учитывает это: повышение баланса увеличивает BongoTap, снижение увеличивает BongoMinus; за операцию меняется не более одного счётчика. Попытка вернуть оба счётчика назад или освободить место их уменьшением несовместима со схемой и удалена. Если оба достигли потолка, восстановить начисление через этот API нельзя.

Установка баланса сначала проходит принятие `SetStat`, затем ожидает callback `UserStatsStored`; мгновенное обновление экрана не считается подтверждением сохранения Steam. Подарок отмечается как отправленный запрос: протокол игры не даёт надёжного подтверждения получения предмета другом. Повторная отправка при неизменном флаге готовности блокируется. При ошибке открытия своего сундука мод останавливает автоматизацию, хотя штатный ChestExchanger может выполнять собственные встроенные попытки.

Лог: `BepInEx/LogOutput.log` или `BepInEx/LogOutput.txt`, в зависимости от настроек загрузчика. Для временного отключения плагина при закрытой игре переименуйте `BepInEx/plugins/BongoCatMods/BongoCat.Mod.dll` в `BongoCat.Mod.dll.disabled`. Для отключения всего загрузчика установите `enabled = false` в `doorstop_config.ini`.

dotnet run --project tests/BongoCat.Mod.Tests -c Release

Проверены SHA-256 всех 202 оригинальных файлов игры: изменения отсутствуют. Пользователь подтвердил работу автопокупки собственных сундуков, смены косметики, улучшение автогифта в 0.1.4 и видимость косметики другим игрокам в 0.1.5. В логе 0.1.2 подтверждено сохранение изменения баланса Steam. Версия 0.1.6 собрана без ошибок и предупреждений, 25 проверок пройдены. Новое закрытие окна ещё требует проверки в игровом интерфейсе.

## Исследование клиента

Анализ установленной версии от 19 октября 2026 года. Файлы игры не изменялись, игра и её сборки не запускались.

- [Архитектура, Steam и план модификации](analysis/ARCHITECTURE.md)
- [Индекс методов и токенов REA](analysis/METHODS.md)
- `analysis/decompiled/Assembly-CSharp/`: 340 восстановленных C#-файлов игровой логики.
- `analysis/decompiled/Heathen.Steamworks/`: 268 восстановленных файлов Steam-обвязки.
- `analysis/decompiled/Helper.Runtime/`: 23 восстановленных файла вспомогательной библиотеки.
- `analysis/raw/rea-evidence.json`: экспорт доказательств REA, включая метаданные, вызовы, обращения к полям и IL-якоря.
- `analysis/raw/install-manifest.json`: размеры и SHA-256 всех 202 файлов установленной версии.

Восстановленный C# и исходные доказательства оставлены локально и исключены из Git. В Git сохраняются отчёт и навигационный индекс. Восстановленный код является представлением декомпилятора, а не оригинальным Unity-проектом; сцены, привязки Inspector, материалы и текстуры в исходный проект не восстановлены.
