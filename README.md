# Bongo Cat Mods

Первый прототип плагина для Steam build `25936063`, Unity `6000.2.8f1`, Windows x64.

## Сборка и установка

Требуются .NET SDK и .NET Framework 4.7.2 reference assemblies. Пути игры можно передать параметром `-GameDirectory`.

```powershell
./scripts/Build.ps1
./scripts/Install.ps1
```

Перед установкой закройте игру. Запускайте её обычным способом через Steam. Окно мода открывается клавишей **F8** или кнопкой **Mods** рядом с игровым меню. Автоматизация начинает каждую сессию выключенной.

Загрузчик: [официальный BepInEx 5.4.23.5](https://github.com/BepInEx/BepInEx/releases/tag/v5.4.23.5), Windows x64. Скрипт проверяет SHA-256 архива, опубликованный GitHub. Плагин проверяет SHA-256 основной сборки игры и отказывается применять патчи при смене версии. Существующий неизвестный загрузчик автоматически не заменяется.

## Функции прототипа

- **General**: установка доступного остатка очков от 0 до 2147483646; восстановление исходных счётчиков текущей сессии; опциональное освобождение места в насыщенном счётчике за счёт уже потраченных очков.
- **Chest automation**: покупка готовых собственных сундуков, выбор косметических/эмоций, общий лимит расхода очков за сессию.
- **Lobby**: подарки выбранным участникам либо всем в текущем лобби. Очки списываются с отправителя, предмет получает адресат. После смены лобби подарки отключаются и выбор участников очищается; бюджет не сбрасывается.
- **Cosmetics**: поиск и выбор стандартных скинов, шляп и бонго; локальное отображение либо публикация ID внешнего вида в лобби; восстановление штатной экипировки.
- **UI**: игровые спрайты панелей/кнопок, шрифты и цвета текущей темы. Окно поддерживает click-through игры через штатный UI raycast и удерживает рендер активным, пока открыто.

Мод не добавляет предметы в Steam Inventory. Передача пользовательских текстур другим клиентам и программа в трее в этот прототип не входят.

До первого изменения счётчиков сохраняется JSON-копия в `BepInEx/config/local.bongocat.mods/backups/`. Она содержит исходные BongoTap/BongoMinus и SteamID, остаётся на этом компьютере. Кнопка Restore возвращает именно значения на момент копии, включая тогдашнее значение потраченных очков. Lifetime-счётчик BongoBeat вручную не меняется.

Установка баланса сначала проходит принятие `SetStat`, затем ожидает callback `UserStatsStored`; мгновенное обновление экрана не считается подтверждением сохранения Steam. Подарок отмечается как отправленный запрос: протокол игры не даёт надёжного подтверждения получения предмета другом. Повторная отправка при неизменном флаге готовности блокируется. При ошибке открытия своего сундука мод останавливает автоматизацию, хотя штатный ChestExchanger может выполнять собственные встроенные попытки.

Лог: `BepInEx/LogOutput.log` или `BepInEx/LogOutput.txt`, в зависимости от настроек загрузчика. Для временного отключения плагина при закрытой игре переименуйте `BepInEx/plugins/BongoCatMods/BongoCat.Mod.dll` в `BongoCat.Mod.dll.disabled`. Для отключения всего загрузчика установите `enabled = false` в `doorstop_config.ini`.

## Проверки

Сборка: 0 ошибок, 0 предупреждений. Регрессионные проверки:

```powershell
dotnet run --project tests/BongoCat.Mod.Tests -c Release
```

15 проверок покрывают граничные значения баланса, сохранение остатка при освобождении места, повторные события готовности, новый цикл сундука и бюджет при переходе между лобби.

Установка и запуск плагина в игре пока не подтверждены: управление окном остановлено пользователем клавишей Escape до этапа установки. Не проверены реальные изменения Steam-статистики, открытия сундуков, подарки, ввод в меню, применение игровых ресурсов и видимость косметики у второго клиента. Наличие компилируемой сборки и успешных проверок не заменяет эти проверки.
